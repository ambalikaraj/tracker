🔥 Firebase Setup (One-Time Only)
📋 Follow these steps:
  1. Go to Firebase Console: console.firebase.google.com
  2. Create Project: Click "Add project" → Name it "Study Tracker" → Continue
  3. Disable Google Analytics (not needed) → Create project
  4. Add Web App: Click the "" (Web) icon → Register app (name: "Study Tracker")
  5. Copy Firebase Config: You'll see a code like this:
    const firebaseConfig = {
      apiKey: "AIza...",
      authDomain: "...",
      databaseURL: "...",
      projectId: "...",
      storageBucket: "...",
      messagingSenderId: "...",
      appId: "..."
    };
  6. Enable Realtime Database:
    • Left sidebar → Build → Realtime Database → Create Database
    • Choose location (closest to you) → Next
    • Start in Test mode → Enable
  7. Enable Google Sign-In:
    • Left sidebar → Build → Authentication → Get Started
    • Sign-in method tab → Google → Enable → Save
  8. Copy Database URL: It looks like: https://your-project.firebaseio.com
  9. Paste values below and click Save
💡 Your config is saved locally and securely. Only you and people you share the URL with can access the data.
